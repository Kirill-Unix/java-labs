# Лабораторные работы

Единый Git-репозиторий лабораторных работ по дисциплине «Основы кроссплатформенного программирования».

## Структура

| Ветка | Работа | Тема |
|-------|--------|------|
| `lr5` | ЛР 5 | Основы объектно-ориентированного программирования |
| `lr6` | ЛР 6 | Массивы и строки |
| `lr7` | ЛР 7 | Статические члены класса |
| `lr8` | ЛР 8 | Наследование и полиморфизм |
| `lr9` | ЛР 9 | Абстрактные классы и интерфейсы |
| `lr10` | ЛР 10 | Интерфейсы |
| `lr11` | ЛР 11 | Перегрузка методов |
| `lr12` | ЛР 12 | Обобщённые типы и коллекции |
| `lr13` | ЛР 13 | Обработка исключительных ситуаций |
| `lr14` | ЛР 14 | Файловый ввод и вывод |
| `lr15` | ЛР 15 | Git и GitHub |

Каждая работа находится в одноимённой подпапке (`lr5/`, `lr6/`, …). Все работы слиты в `main` обычным merge через Pull Request — в истории присутствуют merge-коммиты.

## Запуск

```bash
cd lr5
mvn compile
mvn exec:java -Dexec.mainClass="org.example.Main"
```

Или откройте нужную подпапку в IntelliJ IDEA.
